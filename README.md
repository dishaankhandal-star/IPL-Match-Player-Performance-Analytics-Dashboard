# IPL Analytics Dashboard

## Overview

This project analyzes IPL match and player performance data using Python and Data Analytics techniques.

The objective is to identify:

- Top performing batsmen
- Team win statistics
- Toss impact on match outcomes
- Venue analysis

---

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- SQLite

---

## Dataset

IPL Complete Dataset

Files Used:

- matches.csv
- deliveries.csv

---

## Features

### Top Batsmen Analysis
Identifies the highest run scorers in IPL history.

### Team Performance Analysis
Compares total wins by IPL teams.

### Toss Impact Analysis
Examines whether winning the toss influences match outcomes.

### Venue Analysis
Analyzes the most frequently used IPL venues.

### SQL Integration
Stores processed data inside SQLite database.

---

## Outputs

The project generates:

- top_batsmen.png
- team_wins.png
- toss_impact.png
- venue_analysis.png
